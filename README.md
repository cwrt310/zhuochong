## 小巴桌宠

原生 v2 桌宠文件位于 [`work/xiaoba/native`](work/xiaoba/native)：`pet.json` 和 `spritesheet.webp`。图集为 8 列 × 11 行，单格 192×208，包含九种动画状态及十六个注视方向。

Windows 上运行 `work/安装小巴.ps1`，会将小巴复制到当前用户的 `.codex/pets/xiaoba`，并在 `.codex/config.toml` 中选中、显示小巴。脚本会备份原配置为 `config.before-xiaoba.toml`。安装后如未立即显示，在 Codex 的 Settings > Pets 中刷新。

[`outputs/xiaoba/completed-contact.png`](outputs/xiaoba/completed-contact.png) 是九种动作的总览。用户要求直接安装和提交，本次没有执行最终完整图集质量校验。
